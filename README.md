# Beer Pong VR Unity

Beer Pong VR Unity is a Unity-based virtual reality game developed for Meta Quest. The project recreates the classic beer pong experience in VR using XR interaction, physics-based ball throwing, teleportation movement, scoring logic, timer functionality, audio feedback, and interactive UI elements.

The project demonstrates core AR/VR development skills, including Unity scene setup, C# scripting, object interaction, player movement, game-state management, physics-based gameplay, and immersive user experience design.

## Features

- VR gameplay built in Unity
- Meta Quest support
- XR interaction system integration
- Physics-based ball throwing
- Interactive cups and ball mechanics
- Teleportation-based player movement
- Score tracking system
- Countdown/game timer
- Start and retry UI screens
- Ball respawn functionality
- Audio feedback for gameplay actions
- Trajectory guidance for throwing
- Controller input support, including return/reset functionality

## Technologies Used

## Main Gameplay Overview

The player enters a VR beer pong environment and interacts with the game using VR controls. The objective is to throw the ball into cups using physics-based movement. The game tracks the player's score, manages the timer, provides audio feedback, and allows the player to restart or continue gameplay through interactive UI elements.

## How to Run the Project

1. Clone the repository.
2. Open the project folder in Unity.
3. Allow Unity to restore the required packages.
4. Open the main scene from the `Assets` folder.
5. Connect a Meta Quest headset.
6. Build and run the project for the Android/Meta Quest platform.

## Build Information

The project can be built from Unity using the Android build target for Meta Quest devices. The final build folder may be kept separately from the source repository to avoid storing large generated files in GitHub.
